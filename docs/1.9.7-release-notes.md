# Orbit Store 1.9.7 Community Fork

- **Download from links.** Open **Downloads → Download from links** to add up to 20 direct HTTPS file links. If a link expires, choose **Replace link** and paste a fresh link for the same file.
- **Install through ShadowMountPlus.** Start ShadowMountPlus with its v1 local API enabled. **Install on PS5** sends supported PKG and FPKG files to its package installer. Orbit requests registration for compatible game folders and images and shows the result in Downloads.
- **Free up space.** Review unused downloads and games on the destination drive before deleting anything. Open **Free up space** from Library or from a download that needs more room.
- **Catalogue revision 107.** Browse can sort by **Recently added**. The catalogue includes 33 more games, for 3,090 total.

## Install the Community Fork

Download `orbit_store.elf` and `orbit_store.elf.sha256` from the Community Fork release. Run `shasum -a 256 -c orbit_store.elf.sha256` beside the ELF to verify it. Stop the running Orbit service, then load the new ELF through your payload manager. Open Orbit from the Media tab or visit `http://<ps5-ip>:34177/` from a paired device.

Orbit Zero's **Stream & install** uses ShadowMountPlus browser streaming. Keep Orbit Zero and the console running until installation finishes.

The [upstream 1.9.7 release](https://github.com/saawant12/orbit-store-ps5/releases/tag/v1.9.7) provides the separate native TV app and Orbit Zero installers.
